### 🃏 HighSuit Card Game — Python Desktop App
Full desktop card game rebuilt in Python from a Java original. Features a GUI, rule-based computer opponent, sound effects, persistent high score table, and a standalone `.exe` package. Backed by 107 pytest unit tests and a CI pipeline. Clean layered MVC architecture separating UI, game engine, and domain logic.

**Stack:** Python · PyQt5 · pytest · PyInstaller · GitHub Actions

🔗 [View Repository](https://github.com/Sunnah25/HighSuit-Python)

### 🏦 JPMorgan Chase SWE Simulation — Financial Transaction Microservice
Backend transaction processing microservice built as part of the JPMorgan Chase Advanced SWE virtual experience. Transactions arrive via a Kafka queue, are validated against a database using Spring Data JPA, enriched through an external Incentive REST API, and exposed via a REST endpoint — mirroring real fintech backend architecture. Includes CI pipeline, Docker support, and a Postman collection.

**Stack:** Java · Spring Boot · Apache Kafka · JPA/Hibernate · H2 · Docker · GitHub Actions

🔗 [View Repository](https://github.com/Sunnah25/jpmorgan-swe-simulation)
